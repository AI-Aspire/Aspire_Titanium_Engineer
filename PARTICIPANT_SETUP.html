Titanium Engineer Labs — Setup

Get your local environment running in about 15 minutes. Works on macOS and Windows.

Prerequisites

  • Python 3.12 — from python.org
  • uv — the Python installer/venv manager: install instructions
  • git — from git-scm.com
  • Your APIM subscription key — sent by email from the AIP team
  • Node.js ≥ 22 — only for Module 14's code-mode agent. Skip if you don't need it. nodejs.org
  • Accenture VPN — only for Module 14 Azure Speech. All other modules go through APIM and work without VPN.

1. Clone the repo and switch branches

macOS / Linux / WSL

git clone https://dev.azure.com/LLMGenAITitaniumEngineering/LLMGenAITitaniumEngineering/_git/titanium-engineer-labs
cd titanium-engineer-labs
git checkout ACN_AIP_ADAPTED_LABS

Windows (PowerShell or cmd)

git clone https://dev.azure.com/LLMGenAITitaniumEngineering/LLMGenAITitaniumEngineering/_git/titanium-engineer-labs
cd titanium-engineer-labs
git checkout ACN_AIP_ADAPTED_LABS

2. Create your .env

macOS / Linux / WSL

cp .env.template .env

Windows (PowerShell)

Copy-Item .env.template .env

Open .env in any editor and paste your keys:

APIM_KEY=<your-individual-apim-key>      # required — drives OpenAI, Embed, Anthropic, Cohere
SPEECH_KEY=<shared-speech-key>           # only for Module 14 Voice
TAVILY_API_KEY=<tavily-key>              # optional — Module 13 Deep Research falls back cleanly if empty
Never commit .env. It's in .gitignore. To confirm: git check-ignore .env should print .env.

3. Install the shared environment

macOS / Linux / WSL

make setup

Windows (PowerShell)

uv sync --group dev --group graph --group optim

Takes 2–5 minutes on the first run. Installs LangChain, torch, spaCy, DSPy, and every module dependency except modules 08 and 14 (they have their own venvs).

Windows: don't run bare uv sync. It removes the optional groups. Always include --group dev --group graph --group optim, or install GNU Make and use make setup like macOS.

4. Two modules need their own venv

macOS / Linux / WSL

cd 08_SDG_RAGAS && uv sync && cd ..
cd 14_Voice_Agents && uv sync && cd ..

Windows (PowerShell)

Push-Location 08_SDG_RAGAS; uv sync; Pop-Location
Push-Location 14_Voice_Agents; uv sync; Pop-Location

5. Register Jupyter kernels (so VS Code can find them)

uv run python -m ipykernel install --user --name titanium-engineer-labs --display-name "Titanium Labs (root)"

cd 08_SDG_RAGAS  && uv run python -m ipykernel install --user --name titanium-08-ragas --display-name "Titanium 08 (RAGAS)"  && cd ..
cd 14_Voice_Agents && uv run python -m ipykernel install --user --name titanium-14-voice --display-name "Titanium 14 (Voice)" && cd ..

On Windows PowerShell replace && with ; and cd .. with cd .. (works either way).

6. Verify APIM is reachable

macOS / Linux / WSL

./validate_apim.sh <your-apim-key>

Windows (PowerShell)

.\validate_apim.ps1 <your-apim-key>

# or from cmd.exe:
validate_apim.cmd <your-apim-key>

All 7 checks should say OK. If any fail, check your APIM key.

Windows PowerShell execution policy may block the script. One-time fix for the current session:
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

7. Open in VS Code

code .

Open any .ipynb, click the kernel picker (top-right), and select:

Notebook locationKernel
Modules 02–07, 09–13, 15–23 (most modules)Titanium Labs (root)
08_SDG_RAGAS/*.ipynbTitanium 08 (RAGAS)
14_Voice_Agents/*.ipynbTitanium 14 (Voice)

Known limitations

Module 14 Voice — needs Accenture VPN active. Azure Speech is VNet-restricted and returns 403 without VPN. All other modules work without VPN.
Module 13 Deep Research — needs TAVILY_API_KEY. Without it, the web-search steps skip cleanly and the notebook still runs on the local corpus.
Module 11 Agent Architecture — the last sub-agent cell can take several minutes on gpt-5.5. Be patient; if it times out, restart the kernel and re-run just that cell.

Troubleshooting

ErrorFix
AuthenticationError: 401 missing subscription key Your APIM_KEY is wrong or blank. Check .env.
NoSuchKernel: titanium-08-ragas (or -14-voice) Step 4 or 5 wasn't run for that module. Re-run the two commands for that specific module.
Module 16 says rdflib not installed Wrong kernel selected — pick Titanium Labs (root), not a system Python.
Module 14: 403 Forbidden on cognitiveservices.azure.com Connect Accenture VPN (FortiClient LLM COE HUB), then re-run.
Module 14: Node.js >= 22 not found Install Node 22 (see prerequisites) and restart JupyterLab / VS Code so the kernel picks up the new PATH.
BadRequestError: temperature does not support 0.0 You're on an older commit. git pull and restart the kernel.
Windows: make: command not found Use the direct uv sync --group dev --group graph --group optim command instead.
