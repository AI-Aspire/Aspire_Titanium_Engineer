# Day 1: simple prototyping

*Ends with:* five-minute pitches per group: the problem, the users, two
prompt-only prototypes, and a first set of vibe checks.

## Goals

- Engineering: dev environment, prompt patterns, a first agent, vibe checks and an LLM judge
- Product: a concrete problem worth solving, a product vision, where evals will matter
- Group: a charter in `project/CHARTER.md` and a pitch

## Modules

| # | Module | Demo | Writes |
|---|---|---|---|
| 01 | Dev environment | 30 min | manifest, charter |
| 02 | Prompt patterns | 30 min | prompts |
| 03 | Agents 101 | 35 min | transcripts |
| 04 | Vibe checks and judges | 30 min | rubric, vibe_checks, judge_scores |
