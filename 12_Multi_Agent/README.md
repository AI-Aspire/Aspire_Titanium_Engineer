# Multi-agent report generator

## Learn | Create | Grow

### Learn
Specialist workers behind delegate tools, typed handoff contracts, a supervisor, and a graph that scopes, researches, verifies, writes, and audits citations.

### Create
A report on your own results, generated by the graph over your capability report and RAGAS scores, with its source ledger and citation audit.

### Grow
Production multi-agent systems keep the source ledger and the audit next to every report. Show your team one worker trace that changed the final answer.

**Estimated time:** 50 minutes
**Reads:** capability_report, ragas_scores, corpus
**Writes:** multi_agent_report

## Plain English first

| Term | Meaning |
|---|---|
| Source handle | a `local://` URL that names one section of your evidence, so a citation can be checked |
| Handoff contract | the typed object one agent must return before the next one runs |
| Provenance guard | code that drops any URL an agent did not actually see in a tool result |
| Delegate tool | a tool that runs a whole other agent and returns its structured findings |
| Citation audit | plain code that checks markers, URLs, and duplicates; no model involved |

## What you will do

| Task | What happens |
|---|---|
| 1 | Split the capability report, RAGAS scores, and corpus into sections with stable URLs; two tools over them |
| 2 | Define the contracts, the provenance guards, and the citation audit; test the audit without a model |
| 3 | Build the evals and corpus specialists (plus web when Tavily is set), their delegate tools, the scoper, and the supervisor |
| 4 | Build the verifier, writer, and evaluator, and wire the six nodes into a LangGraph |
| 5 | Run it on your own results, read the audit, and save the report |

## Before you arrive

- Take one report your team wrote and check whether each claim cites a source you could open; count the ones that do not.
- How we built our multi-agent research system: https://www.anthropic.com/engineering/multi-agent-research-system

## Setup

```bash
make setup
uv run jupyter lab      # open 12_Multi_Agent/Report_Generator.ipynb
```

Needs `OPENAI_API_KEY` and `LLM_MODEL` in `.env`. `TAVILY_API_KEY` is optional: with it, a web specialist joins the run; without it, the factory works from your own results and corpus.

## Data files

None in this folder. Reads `capability_report`, `ragas_scores`, and `corpus` from the workspace, writes `multi_agent_report`.
