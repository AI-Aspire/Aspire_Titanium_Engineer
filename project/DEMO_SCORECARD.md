# Demo scorecard

Judges score each criterion 0 to 5. The group's own harness supplies the
evidence column; a claim without evidence scores at most 2.

| Criterion | Score | Evidence from the workspace |
|---|---|---|
| The problem is real and the users are named | | charter |
| The prototype answers the users' questions | | baseline_runs, agentic_runs |
| Retrieval is measured, not assumed | | ladder, ragas_scores |
| The agent is tested against tasks | | trajectories, capability_report |
| Failure modes are known and guarded | | guardrail_cases, owasp_findings |
| The release decision is evidence-based | | release_decision, risk_register |
| The demo runs live | | |
